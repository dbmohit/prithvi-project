## 🌐 Website Overview & Architecture

This repository contains the official project website for the **PRITHVI** initiative, engineered with a modern cosmic atmospheric dark theme, responsive multi-package filtering, an interactive SVG/CSS workflow diagram, and comprehensive consortium profiles.

### 📁 Pages & Structure

- **[`index.html`](index.html)**: Main project portal with hero stats, scientific motivation, interactive multi-tier flowchart, Work Package overview, sectoral impact cards, consortium leadership, technical benchmarks, and HPC architecture.
- **[`wp.html`](wp.html)**: Dedicated Work Packages page with interactive filtering (`All`, `WP1`, `WP2`, `WP3`, `WP4`), institutional lead breakdowns, deliverables, and modal viewer for the original proposal schematic (Fig 1).
- **[`team.html`](team.html)**: Dedicated Consortium Investigators page featuring genuine portrait photos, institutional affiliations, and research roles for the Lead PI, all 6 Co-PIs, and industry partners.
- **[`assets/css/prithvi.css`](assets/css/prithvi.css)**: Custom responsive stylesheet featuring glassmorphism, animated glow badges, and custom flow connector lines.
- **[`assets/js/prithvi.js`](assets/js/prithvi.js)**: Interactive logic for WP filtering, modal dialogs, and mobile navigation.
- **[`assets/images/team/`](assets/images/team/)**: Extracted high-resolution portrait photos for all investigators.

## 🚀 How to View Locally

Open in any web browser:
```bash
xdg-open index.html
```

Or run a local HTTP server:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
